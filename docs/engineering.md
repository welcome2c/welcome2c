## Android 앱의 인증 화면과 화면 생명주기

**프로젝트:** 한화생명 영업지원 Android 앱

앱 내 인증은 로그인 화면뿐 아니라 등록·재등록·실패·인증수단 변경·설정 복귀까지 이어지는 사용자 흐름입니다.\
중복 요청이나 화면 전환 시점이 어긋나면 인증 SDK의 거래 상태와 사용자에게 보이는 화면 상태가 달라질 수 있습니다.

- OnePass 중복 요청과 거래 상태 정합성을 개선했습니다.
- 인증 관리자 리소스 해제 시점과 인증수단 저장의 일관성을 정리했습니다.
- 다른 인증수단으로 전환할 때 결과 콜백이 전달되지 않는 경로를 수정했습니다.
- navigation result와 콜백이 saved state의 Parcel 직렬화 대상에 포함되며 발생하는 크래시를 수정하고, 결과 전달을 메모리 상태로 분리했습니다.

**핵심:** 인증 상태, 화면 상태, 결과 전달과 리소스 수명을 함께 고려했습니다.

## 다국어·태블릿을 고려한 Compose 디자인 시스템

**프로젝트:** 공통 Compose 컴포넌트와 Catalog

같은 글자 수라도 언어와 폰트에 따라 실제 표시 폭이 달라집니다.\
공통 UI는 개별 화면의 예외를 흡수하면서도 호출부가 일관되게 사용할 수 있어야 합니다.

- 글자 수 기준이었던 탭 라벨 제한을 `TextMeasurer` 기반의 실제 폭 측정으로 변경하고 다국어 말줄임을 지원했습니다.
- 태블릿 여부에 따른 타이포그래피와 간격 처리를 구성했습니다.
- 공통 컴포넌트의 컬렉션을 `ImmutableList`로 전환하고 안정성 어노테이션의 사용을 정리했습니다.
- `remember`, 리스트 key와 스타일 캐싱으로 반복 계산과 불필요한 상태 생성을 줄이는 방향으로 개선했습니다.
- 컴포넌트 API 변경을 앱과 Catalog 호출부에 함께 반영했습니다.

**핵심:** 공통 컴포넌트의 표시 방식, 상태 계약, 검증 화면을 함께 관리했습니다.

## AI 코드 리뷰의 초기 구축과 출력 검증

**프로젝트:** GitLab CI 기반 개발 도구

리뷰 모델의 출력은 실제 변경 파일과 코드 위치에 연결돼야 사용할 수 있습니다.\
AI가 제시한 행 번호를 그대로 신뢰하지 않도록 리뷰 결과의 게시 경로까지 설계했습니다.

- Claude API 기반 리뷰 파이프라인을 최초 구축했습니다.
- 초기 설계에서 리뷰 목적에 따라 모델과 프롬프트를 분기했습니다.
- diff 처리 중 커밋 헤더가 유실되는 문제를 수정했습니다.
- diff에서 코멘트를 달 수 있는 파일·행의 집합을 추출하고, 모델 출력의 대상 위치를 검증했습니다.
- 리뷰 결과의 커밋 코멘트와 Slack Block Kit 알림을 연결했습니다.

**핵심:** 모델 호출과 함께 입력 범위·출력 위치·협업 도구 연결을 다뤘습니다.\
이 사례는 직접 기여한 초기 구축과 개선 범위를 설명합니다.

## WeatherCast: 앱과 위젯의 데이터·이미지 복구

**제품:** [오늘뭐입지 · WeatherCast](https://play.google.com/store/apps/details?id=kr.dev.hoony.weathercast) · Android / iOS

네트워크 응답이 늦거나 위젯의 실행 시간이 짧아도, 사용자는 마지막으로 확인한 정보와 현재 상태를 구분할 수 있어야 합니다.

- 캐시된 날씨를 먼저 표시하고 최근 데이터를 재사용하는 흐름을 개선했습니다.
- 대기질 조회의 재시도와 측정 시각을 고려한 이전 값 표시를 보완했습니다.
- Android에서는 위젯 이미지 복구 작업을 `WorkManager`에 연결했습니다.
- iOS에서는 위젯 이미지의 백그라운드 전송과 복구 경로를 보완했습니다.
- 원격 일러스트 캐시와 기존 사용자 설정을 고려하며 양 플랫폼의 업데이트를 이어가고 있습니다.

**핵심:** 앱과 위젯의 서로 다른 수명 안에서 정보와 이미지를 복구하는 운영 경험입니다.

## GemiBoard: 한글 입력과 천지인 조합

**제품:** [GemiBoard](https://play.google.com/store/apps/details?id=kr.dev.hoony.gemiboard) · Android

키보드는 자모 조합뿐 아니라 연속 입력의 시간, 삭제, 커서 이동과 입력 대상 앱의 상태를 함께 다뤄야 합니다.

- `InputMethodService` 기반 키보드와 한글 오토마타를 구현했습니다.
- 천지인 조합기를 통해 복합 모음과 연속 탭 입력을 처리했습니다.
- 시간 주입이 가능한 조합기 구조와 입력 시퀀스 테스트로 타임아웃·자모 전환·복합 모음 처리를 확인할 수 있게 구성했습니다.
- 입력된 텍스트의 AI 교정·변환 기능을 키보드 흐름에 연결했습니다.

**핵심:** Android 입력 서비스와 상태를 가진 조합 로직을 함께 다룬 경험입니다.
